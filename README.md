# VAR-Streamlit

Dashboard Streamlit de prevision VAR pour les series temporelles `heater` et `ice cream`.

## Application en ligne

[Ouvrir le dashboard Streamlit](https://var-app-alkqyzqekbkkgxccubj8ey.streamlit.app/)

## Lancer localement

```bash
pip install -r requirements.txt
streamlit run app.py
```

Le dashboard permet d'explorer les donnees, choisir l'ordre du modele VAR, ajuster l'horizon de prevision et consulter les diagnostics statistiques.
